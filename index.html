Belum ada game yang cocok. Coba kata kunci lain.

1. Unggah data siswa

Gunakan file FORMAT_PRESENSI_SISWA (.xlsx). Satu sheet = satu kelas; nama kelas dibaca dari baris “KELAS / FASE”, nama siswa dari kolom “NAMA PESERTA DIDIK”. Boleh memilih beberapa file sekaligus (kelas X, XI, XII). Mengunggah ulang sebuah kelas akan menggantikan data kelas itu saja.

2. Periksa dan simpan

NamaKelas
Agar terbaca di semua game dan di perangkat siswa: unggah berkas siswa.json ke folder yang sama dengan index.html (Firebase: folder public/; GitHub: halaman utama repository), lalu deploy atau commit. “Simpan di perangkat ini” hanya berlaku di tablet atau komputer yang sedang dipakai.
Catatan privasi: situs ini bersifat publik, jadi siswa.json bisa dibaca siapa saja yang tahu alamatnya. Dari file Excel hanya nama dan kelas yang diambil; NISN/NIS tidak dibaca dan tidak disimpan.
